06 · 瞳孔测量（现行算法）pupil measurement (current method)

上点被眼睑挡住，所以不用它：左右两点定中心，下点定半高The top point hides under the lid, so it is not used: left and right set the centre, bottom sets the half-height

红色椭圆是现行算法，量的是整个瞳孔；蓝色是已废弃的四点法，只量到露出来的部分The red ellipse is the current method and measures the whole pupil; blue is the retired 4-point method and sees only the exposed part

三点端点法（现行）3-point endpoint (current)四点法（已废弃）4-point (retired)
center_x = (L.x + R.x) / 2    center_y = (L.y + R.y) / 2
width = |R.x − L.x|    height = 2 × (B.y − center_y)
area = π/4 × width × height
证据：上点在左右连线上方 66 px，下点在下方 138 px（人工标注：75 / 140 px）。完整的椭圆应当上下对称，所以上点标到的是"露出来的上沿"。端点法得到的高宽比是 0.93，接近正圆。Evidence: the top point sits 66 px above the left–right line, the bottom point 138 px below (human labels: 75 / 140 px). A complete ellipse is symmetric, so the top label marks the exposed edge. The endpoint method gives height/width 0.93, nearly round.
